# Marina Diaz de Pacheco Memorial Website

Static memorial website designed for GitHub Pages and the custom domain `marinadiazdepacheco.com`.

## Pages
- `index.html` — memorial home page
- `services.html` — St. Cyprian rosary/Mass and Forest Lawn Cypress niche burial
- `celebration.html` — Flecha Cantina Celebration of Life and parking
- `memories.html` — photo/video submission page

## Replace placeholders
1. Put Marina's portrait in `images/` and update the homepage placeholder.
2. Add St. Cyprian parking image/map.
3. Add Forest Lawn niche location once selected.
4. Add Flecha parking photos.
5. Create a Google Form with a File Upload question and replace the placeholder submission setup on `memories.html` with the form URL.

## GitHub Pages
Upload this entire folder to a GitHub repository. In repository Settings → Pages, deploy from the main branch/root folder.

## Cloudflare domain
Keep the `CNAME` file in the repository. In Cloudflare DNS, point the domain to GitHub Pages according to GitHub's current custom-domain instructions. Enable HTTPS after GitHub verifies the domain.
